# Homebrew tap

This tap contains the `kcx` formula.

## Install

```sh
brew tap yutayamate/tap
brew install yutayamate/tap/kcx
```

The formula builds from a pinned `kcx` source revision and requires the Swift Command Line Tools.

## Formula updates

GitHub Actions checks the latest stable `kcx` release hourly. When a new release appears, it updates the formula to the release tag and commit automatically.
